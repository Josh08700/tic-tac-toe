### How to Run

**Prerequisites:** Install & open Docker Desktop.

1. Clone repo & navigate into folder:
   git clone https://github.com/Josh08700/tic-tac-toe.git && cd tic-tac-toe

2. Launch app:
   docker compose up --build

3. Play live in browser:
   http://localhost:8080

4. Stop app:
   Ctrl + C  (or: docker compose down)
